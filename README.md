# NESU — Sovereign Settlement

A conceptual proposal page for the Nur Energy Settlement Unit (NESU): a gold- and
commodity-backed, Sharia-compliant settlement instrument for sovereign energy trade,
starting with the Algeria–EU gas corridor.

Trilingual: English, French, and Arabic (with right-to-left layout), switchable with
the EN / FR / ع buttons in the top right.

This is a separate, standalone project — not connected to digital-uni or to the
Green Euro-Dinar Corridor Token site. It shares only the "Digital-UNI" branding
credit, not any code or hosting.

## What's on the page

- The core NESU concept and design principles
- The five Algeria trade corridors (Europe, Gulf, US, Asia, Africa)
- A direct comparison against Bitcoin
- The environmental-accountability mechanism (GCRS)
- Real-world precedents (Project mBridge, Buna, e-CNY)
- An honest roadmap of what would actually need to happen next
- An open letter to banking and securities regulators in Europe and the Middle
  East, raising the specific classification and licensing questions this design
  poses in Switzerland, the EU, Algeria, and the Gulf — not a private engagement
  letter to any one law firm, and not legal advice

## Deploying

This is a single self-contained static HTML file (`index.html`) — no build step,
no framework, no dependencies. Upload it to a new GitHub repo and import that repo
into Vercel; Vercel will detect it as a static site automatically and it will just
work, with no configuration needed.
